# Finsspire Financial Services website

Mobile-friendly static website for general loan assistance.

## Planned DRA wording
Debt Recovery Agency (DRA) services are described as a future planned offering only. The website explicitly says Finsspire is not currently providing this service and is not currently empanelled or contracted by any bank or NBFC.

## Before publishing
- Replace the empty `mailto:` link in `index.html` with a verified business email.
- Confirm the description matches the actual business model.
- Obtain qualified Indian regulatory advice before beginning loan facilitation or recovery-agent activity.
- Do not collect identity, bank, or financial documents through an unsecured form.

## Publish
Upload `index.html` to the GitHub repository, then connect it to Cloudflare Pages.
